# MouseBatteryTray 鼠标电量任务栏显示

一个轻量的 Windows 鼠标电量工具：在通知区域显示绿色圆角电池图标和电量数字，并根据**最近产生输入的鼠标**切换设备。支持 Windows 提供的设备电量，并为部分迈从（MCHOSE）2.4G 接收器直接读取真实电量。

![绿色电池图标与深浅色任务栏尺寸预览](assets/icon-preview.png)

预览图中的数字用于展示外观；程序运行时显示鼠标实际返回的百分比。

## 功能

- 鼠标移动或点击后，使用 Windows Raw Input 识别实际产生输入的鼠标。
- 启动时读取电量，之后每 30 秒在后台刷新；设备插拔时也会重新检测。
- 绿色填充、深色数字、灰色圆角边框和浅色内圈；适配 16、20、24、32、48 像素托盘尺寸。
- 已知电量统一显示绿色，不再按低电量阈值变成黄色或红色；未知电量使用灰色图标和 **?**。
- 右键菜单支持选择或固定设备、立即刷新和退出；双击图标也可刷新。
- 支持的迈从接收器可显示设备名称、2.4G 连接方式和电量；有充电信息时显示“充电中”。
- 可安装到当前用户目录，并在登录 Windows 后自动启动；无需管理员权限。
- 接收器暂时不回复时，保留本次运行中同一设备最近一次成功读取的电量，并注明上次读取时间；不把其他鼠标的电量套用到当前设备。

## 下载与运行

Windows 10/11 用户可直接运行 [release/MouseBatteryTray.exe](release/MouseBatteryTray.exe) 体验。安装自启动则运行 [scripts/install.bat](scripts/install.bat)；卸载运行 [scripts/uninstall.bat](scripts/uninstall.bat)。安装脚本从 release 目录查找 EXE，因此下载 ZIP 后应保留目录结构。

右键单击通知区域图标可选择设备、立即刷新或退出。如果图标藏在 **^** 隐藏图标菜单，可以将它拖到任务栏常驻。退出仅结束当前进程；下次登录仍按自启动设置运行。

已安装旧版的用户，可下载新版并重新运行安装脚本以替换程序。只运行 release 目录中的 EXE 是临时体验，不会自动替换已安装的版本或修改自启动设置。

## 电量如何更新

- **自动更新**：启动时读取一次，之后每 30 秒读取一次；设备插拔触发重新检测。
- **手动更新**：右键选择“立即刷新”，或双击托盘图标。
- **唤醒重试**：鼠标移动后，若当前电量未知或显示的是缓存值，会重试读取；输入触发的重试至少间隔 3 秒。
- **休眠与缓存**：支持的迈从接收器暂时不回应时，显示上次成功读取的数值，悬浮提示和菜单注明“上次读取 HH:mm”。缓存仅保留在当前进程内，设备被扫描为断开或程序退出后不保留。首次尚未读到电量时显示 **?**，移动鼠标唤醒后可重试。

程序不按使用时间估算电量，也不会自行递减数字。数值变化取决于鼠标固件返回的百分比和精度；连续几次读取相同数值属于正常情况。后台读取不会阻塞托盘菜单。

## 从源码构建

双击 [build.bat](build.bat)，构建结果写入 release 目录。脚本调用 Windows 自带的 .NET Framework C# 编译器，编译 src 目录下的所有 C# 文件，不依赖 NuGet 或网络下载。

主程序位于 [src/MouseBatteryTray.cs](src/MouseBatteryTray.cs)，迈从接收器读取逻辑位于 [src/ReceiverBattery.cs](src/ReceiverBattery.cs)。

在项目根目录使用 PowerShell 可运行测试与生成预览：

```powershell
.\scripts\test.ps1
.\scripts\preview.ps1 -OutputPath "$env:TEMP\MouseBatteryTray-green-preview.png"
```

测试覆盖实际捕获的接收器报文、百分比解析、校验失败、设备匹配和后台刷新，也会尝试扫描本机设备；无需连接指定鼠标即可运行。预览脚本调用已构建程序的实际图标渲染方法，生成外观示例，不会修改设备设置。

## 蓝牙与 2.4G 模式

程序通过 Windows Raw Input 识别当前使用的鼠标。蓝牙等设备优先使用 Windows 公布的电量属性；对于支持的迈从接收器，通过 HID 设备信息查询直接读取电量，并按设备容器关联到对应鼠标，避免误配到触控板或其他设备。查询只读取设备信息，不修改鼠标设置。

| 连接或设备 | 当前支持情况 |
| --- | --- |
| Windows 提供电量属性的设备 | 读取系统报告的百分比 |
| MCHOSE A7 V3 Ultra+ 的 2.4G 接收器 | 已在实机验证，可直接读取真实电量和连接方式 |
| 使用兼容旧版或新版 HID 协议的部分迈从设备 | 已实现协议读取，但其他型号尚未逐一实测 |
| 其他未提供系统电量、且无兼容读取协议的 2.4G 设备 | 显示 **?**，不代表支持所有品牌的接收器 |

切换连接方式后，移动鼠标以识别新的输入设备。固定的设备未连接时，程序会临时跟随当前鼠标，菜单会提示“固定设备未连接”；也可以手动重新选择设备。启动时若只有一个可读电量的鼠标，会先显示该鼠标电量。

本项目在任务栏通知区域添加自己的图标，不修改系统电池图标。图标的精确排列顺序由 Windows 控制。

## 隐私与资源

程序在本机读取鼠标设备 ID、电量与原始输入设备句柄，并向兼容接收器发送电量/设备信息查询；不记录鼠标轨迹、不读取键盘内容、不发送网络请求。仅在当前用户注册表保存手动固定设备的 ID；安装脚本也在当前用户注册表设置自启动。

图标字体优先使用用户已安装的 Apple SF Pro；项目不分发该字体。未安装时优先使用 Segoe UI Variable Display，再回退到 Segoe UI。
